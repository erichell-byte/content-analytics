Privacy Policy

Effective: October 19, 2026

Current website

This is a static informational website. It has no account login, analytics backend, tracking scripts, forms, or TikTok API connection. The website itself does not request or store TikTok personal data. Hosting is provided by GitHub Pages, which may process technical request information under GitHub's own policies.

Planned TikTok integration

After development and appropriate authorization, Content Analytics is intended to retrieve TikTok account identity and published video metrics (such as views, likes, comments and shares) using the permissions the user grants. These data would be used only to display performance reports. Token handling, storage, retention and deletion procedures must be finalized and this policy updated before enabling TikTok authorization.

Sharing

We do not currently sell or share TikTok user data. The future integration will require its own secure server-side authorization implementation.

Changes

This policy will be updated before any new data processing begins. The project owner should publish contact details and a data-deletion request method before activating external user access.
